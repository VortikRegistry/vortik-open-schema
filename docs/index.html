Protocol signals

High-value source states that materially affect how Vortik describes Ethereum coordination as of 2026-09-13.

ePBS / epbs.eth

EIP-7732 is a Review Core EIP Scheduled for Inclusion in Glamsterdam. Platåberget and devnet-9 provide public implementation-facing evidence. EIP-8282 adds explicit builder deposit and exit request paths.

FOCIL / inclusionlist.eth

EIP-7805 remains Declined for Inclusion in Glamsterdam and Scheduled for Inclusion in Hegotá. This is a fork-scoped source state, not an activation or deployment claim.

Block-Level Access Lists

EIP-7928 is Scheduled for Inclusion in Glamsterdam and appears in current Glamsterdam testing. BALs remain distinct from ePBS and from state/gas repricing proposals.
